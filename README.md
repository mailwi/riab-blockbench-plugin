**This repository does not contain the source code for Blockbench Converter.**

To **download** Blockbench Converter, go to the releases page: [link](https://github.com/mailwi/riab-blockbench-plugin/releases/tag/blockbench_converter)

**Blockbench Converter** - a program that converts **Blockbench** models to a supported format for **RPG in a Box**. It also includes many other features, such as the implementation of the scripting language **Bxite**.
